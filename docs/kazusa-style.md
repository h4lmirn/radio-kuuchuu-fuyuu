# カズサ文体の型（ラジオ台本用）

2026-11-07、先生の指示でまとめた。出典は、公式ボイス（『楽しんでますか、先生？』2024・2025、ボイス集、誕生日ボイス）と、pixiv のカズサ二次創作小説のセリフ。台本の文章をこの型に合わせる。

## 先生の呼び方

- 基本は「先生」。ただし呼びかけは文頭とは限らない。文中や文末に置く形がカズサらしい（「じゃあ行こうか、先生」「ごめん、先生」）
- 「せんせ」：ひらがな。眠いとき、力の抜けたとき、素に近いとき。「おはよ、せんせ。」
- 「センセ」：カタカナ。少し突き放した、茶化した距離感。「センセ、おはよう。」
- あえて改まった形もたまに使う。「先生、おはようございます。」のように、きちんとしすぎる言い方自体が遊びになる。毎回はやらない

## 挨拶の型

- 「おはよ、せんせ。」（短く、語尾を落とす）
- 「センセ、おはよう。」
- 「先生、おはようございます。」（あえて改まる）
- 「起きて、先生」（今までのラジオの型。これも呼び方バリエーションに含める）

## 文のリズム

- 1フレーズは短く、5〜20字くらい。言い切らずに切ることもある
- 「…」での言いよどみ・途切れが多い。ただしラジオの台本では読み上げの都合で多用しない
- 挟み言葉：「さ」（文中）、「まあ」「なんか」「一応」「案外」
- 語尾：「〜だよ」「〜じゃん」「〜でしょ」「〜かな」「〜ね」。疑問は「〜？」で、か を付けないことが多い
- 縮めた形：「〜ちゃう」「〜だめ」「言わない方がいいよ」

## 中身の型

- 心配と小言を、平たい言い方で言う。「頑張りすぎだからさ、しっかり楽しんでよ」「先生は寝ちゃだめだよ」「遅刻はダメだからね」
- からかいは真顔で。「その驚いた顔が見たかったから」「襲われちゃうから」
- 好意はさらっと言う。重くしない
- 食べ物（スイーツ）の話になると少しだけ饒舌になる

## 避ける形

- ハツラツとした元気な言い回し、感嘆符の連打
- 長い説明文。ニュース本文は今まで通り正確に、ただし導入と締めの地の文をこの型に寄せる
- です・ますを地の文の基本にしない（改まった形の遊びとしてだけ使う）
